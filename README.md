# PentaSLAMBot

## 🚀 Project Overview
This project explores the integration of modern robotics frameworks and high-performance single-board computers in autonomous systems. Utilizing the Raspberry Pi 5, we deployed ROS 2 Jazzy to manage a differential-drive hardware platform. The research focused on two primary domains: spatial awareness and autonomous locomotion. We successfully implemented SLAM for dynamic mapping and localization. Furthermore, we developed and validated a proprietary navigation algorithm tailored for the robot's kinematic constraints. The results demonstrate an optimized balance between computational efficiency on edge devices and robust navigational accuracy in indoor environments.
